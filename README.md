# Ruiyang Ren — Academic Homepage

Live website: [rui-yang.ren](https://rui-yang.ren)

- `index.html`: biography, experience, awards, and academic service.
- `publications.html`: complete publication list, grouped by preprints and publication year.
- `styles.css`: shared desktop and mobile styles.
- `portrait.webp`: optimized profile photo used by the homepage.
- `self-photo.jpg`: original photo retained for future exports.
- `favicon.svg` / `favicon.png`: website icons.
- `social-card.png`: preview image for shared links (1200 × 630).
- `CNAME`: custom domain configuration.

This is a static website with no build step. Open `index.html` locally to preview both pages. Keep the Home / Publications navigation consistent across the two HTML files. Prefer verified publisher or conference links for published papers.

GitHub Pages publishes the `gh-pages` branch. After checking the changes locally, commit and push to deploy.
